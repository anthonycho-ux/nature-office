## Research Process

All coding agents must follow the research process documented in [CONTRIBUTING.md](../CONTRIBUTING.md):

1. **Conduct web research** using Google AI models before implementing features
2. **Document findings** in this directory with proper formatting
3. **Update CONTRIBUTING.md** with new research requirements
4. **Validate through CI** - GitHub Actions enforces research requirements

## How to Add Research

1. Use `scripts/research_tools.py` to create properly formatted research files
2. Run `scripts/validate_research_requirements.py` to validate
3. Commit with research references in commit message
4. Update this index manually or use the automated tools

## Research Quality Standards

All research must meet these criteria:
- **Currency**: Information from 2024-2026 only
- **Authority**: Official sources, peer-reviewed, industry experts
- **Completeness**: Technical, regulatory, and market aspects
- **Verification**: Cross-referenced with 2+ independent sources
